# Design decisions

These notes connect [[Welcome|reading]] with [[Project|writing]].

## A guiding principle

**Keep the document portable.** Personal reading notes belong beside the experience, not inside someone else's Markdown.

## Small by design

Local files are the source of truth. A bounded in-memory index adds connections; it does not become a second permanent copy of the notebook.

A calm editor should make the next useful action easy. ^next-action

## What stays out

No accounts, background HTTP requests, plugin runtime, or hosted publishing service. Explicit web links open in your normal browser when you choose them.
