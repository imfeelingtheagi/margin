# The quiet workspace

A folder becomes a notebook without importing your files into a database. Link to [[Welcome|the starting page]] and keep [[Decisions|decisions]] close to the work.

## Working notes

Use **Live** to write with the rendered page around you. Click a paragraph to reveal its original Markdown, then move to another block to see it rendered again.

| Task | View |
| --- | --- |
| Read a long document | Read |
| Draft and revise | Live |
| Inspect exact syntax | Edit |
| Compare source and output | Split |

## A small model

Inline math stays local: $E = mc^2$. A display equation works too:

$$
\text{useful notes} = \text{clear ideas} + \text{good connections}
$$

> [!NOTE]+ Keep the source readable
> Rendering changes how a note looks, not how its Markdown is stored.
